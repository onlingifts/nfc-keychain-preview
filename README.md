# Child Emergency NFC Card Generator

نسخة جديدة من موقع المعاينة السابق، مخصصة لإنشاء رابط طوارئ للطفل ووضعه على ميدالية NFC.

## التدفق
1. إدخال معلومات الطفل ووليي الأمر.
2. معاينة البطاقة مباشرة.
3. إنشاء رابط عرض عام واحد.
4. نسخ الرابط وبرمجته على NFC.
5. لا توجد حسابات ولا روابط تعديل. عند وجود خطأ يتم إنشاء بطاقة جديدة.

## الخصوصية
- الصفحة العامة عليها noindex.
- لا يوجد API تعديل أو حذف من واجهة العميل.
- يجب أن يكون الـ backend مستقلاً مع منع القراءة المباشرة للجدول، والوصول للبطاقات فقط عبر public_id عشوائي.
- يفضل عدم إدخال عنوان المنزل الكامل أو معلومات غير ضرورية.

## النشر
الواجهة Static على GitHub Pages.
الحفظ الدائم يحتاج خدمة backend مستقلة. الملف config.js يحتوي عنوان API فقط بعد إنشائها.
