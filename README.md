# NFC Keychain Preview

مشروع مستقل كلياً لتجربة ميدالية NFC وصفحة العميل قبل الطلب.

## الوظائف الحالية
- رفع لوغو PNG/JPG/WEBP
- إزالة تقريبية للخلفية البيضاء داخل المتصفح
- تحويل اللوغو بصرياً إلى معاينة ميدالية ذهبية مع حلقة
- معاينة صفحة NFC باسم العميل وروابطه
- زر طلب يفتح WhatsApp برسالة جاهزة
- لا يتم رفع صور العملاء إلى سيرفر في هذه النسخة؛ كل المعالجة محلية داخل المتصفح

## النشر
يمكن نشر المشروع مباشرة على GitHub Pages لأنه Static HTML/CSS/JS ولا يحتاج Backend.
